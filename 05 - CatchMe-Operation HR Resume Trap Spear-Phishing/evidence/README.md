# Evidence handling

Do not publish the original email, raw workstation artifact, original malicious document, or suspicious executable payloads unless redistribution is explicitly authorized. This repository contains analysis notes and the evidence register, not the original sensitive evidence. Preserve original files unchanged and store working copies separately. Hash every acquired/derived file and document the method. Analyst-transcribed outputs in `outputs/` are notes based on console output supplied during the investigation, not substitutes for original forensic exports.
