# Sanitized Email Evidence

These files are sanitized derivatives prepared for public portfolio use.

- Original evidence is retained separately and is not included in this public directory.
- Recipient and message-routing details have been removed or redacted.
- Sanitization may alter message structure and file hashes.
- These copies must not be used to validate the original evidence's integrity.
- Indicators extracted from these messages are not automatically malicious; destination and reputation require independent validation.

The original evidence and its integrity records should be retained in the authorized investigation environment.
